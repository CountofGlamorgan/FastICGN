# FastICGN v1.0.0 Release Checklist

> **Historical record.** This is the checklist used for the v1.0.0 tag
> (`9ebdc6f`, 2026-07-03) on the original lab deployment. Paths, tools and
> steps are those of that date; it is not maintained and is not a current
> procedure.

Scope: prepare a reproducible source tag and scratch release build without
overwriting `/home/chonglang/opencorr-gpu-mvp-build/opencorr_cli_cuda_mvp`.

## Preconditions

- Source tree: `/home/chonglang/opencorr-gpu-mvp-src`
- Production binary directory: `/home/chonglang/opencorr-gpu-mvp-build`
- Release build directory: `/tmp/opencorr-gpu-v1.0.0-build`
- CUDA compiler: `/usr/local/cuda-13.2/bin/nvcc`

The release tree must be clean before tagging:

```bash
git -C /home/chonglang/opencorr-gpu-mvp-src status --short
```

## Tag

Create the release tag only after all release-hardening changes are committed:

```bash
git -C /home/chonglang/opencorr-gpu-mvp-src tag -a v1.0.0 -m "FastICGN v1.0.0"
git -C /home/chonglang/opencorr-gpu-mvp-src rev-parse --short=12 HEAD
git -C /home/chonglang/opencorr-gpu-mvp-src rev-parse --short=12 "v1.0.0^{commit}"
```

The two hashes above must match for the intended release. For annotated tags,
`git rev-parse v1.0.0` returns the tag object hash, not the commit hash; use
`v1.0.0^{commit}` for release provenance checks.

## Release Build

Always configure from scratch after checking out the intended release commit or
tag. The version header is generated by CMake at configure time.

```bash
rm -rf /tmp/opencorr-gpu-v1.0.0-build
cmake -S /home/chonglang/opencorr-gpu-mvp-src \
  -B /tmp/opencorr-gpu-v1.0.0-build \
  -DCMAKE_CUDA_COMPILER=/usr/local/cuda-13.2/bin/nvcc \
  -DCMAKE_BUILD_TYPE=Release
cmake --build /tmp/opencorr-gpu-v1.0.0-build -j$(nproc)
```

Do not use an already configured build tree after moving `HEAD` or retagging.
`src/opencorr_gpu_mvp_version.h.in` is expanded into
`<build>/opencorr_gpu_mvp_version.h` during `cmake -S ... -B ...`; a plain
`cmake --build` does not refresh the embedded git hash.

## Provenance Check

```bash
/tmp/opencorr-gpu-v1.0.0-build/opencorr_cli_cuda_mvp --version
git -C /home/chonglang/opencorr-gpu-mvp-src rev-parse --short=12 HEAD
git -C /home/chonglang/opencorr-gpu-mvp-src rev-parse --short=12 "v1.0.0^{commit}"
```

Acceptance:

- `--version` prints `git_hash=<hash>`.
- `<hash>` equals both `HEAD` and the `v1.0.0` tag target commit.
- The build was produced in `/tmp/opencorr-gpu-v1.0.0-build`.
- No file in `/home/chonglang/opencorr-gpu-mvp-build` was replaced.
